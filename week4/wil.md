React는 2013년 페이스북에서 개발된 사용자 인터페이스 라이브러리로, 복잡한 화면을 효율적으로 만들기 위해 등장했다. 기존의 방식은 DOM을 직접 조작해야 했기 때문에 코드가 복잡해지고 유지보수가 어려웠지만, React는 Virtual DOM을 통해 변경된 부분만 업데이트하는 방식을 사용하여 성능과 효율성을 높였다. 이후 2019년에는 Hook이 도입되면서 함수형 컴포넌트에서도 상태 관리와 다양한 기능을 사용할 수 있게 되었고, 현재는 이 방식이 표준으로 자리 잡았다.

React에서 state는 컴포넌트 내부에서 관리되는 변화 가능한 데이터이며, 값이 변경되면 화면이 자동으로 다시 렌더링되는 특징을 가진다. 이를 통해 사용자의 입력이나 이벤트에 따라 UI가 자연스럽게 변하도록 구현할 수 있었다.

Hook은 함수형 컴포넌트에서 state와 같은 기능을 사용할 수 있도록 도와주는 도구로 등장했다. useState를 통해 상태를 선언하고 변경할 수 있었으며, useEffect를 통해 특정 시점에 코드를 실행할 수 있었고, useRef를 통해 DOM 요소에 접근하거나 값을 유지할 수 있었다. 이러한 Hook의 도입으로 코드가 더 간결해지고 재사용성이 높아졌으며, 클래스형 컴포넌트보다 이해하기 쉬운 구조를 만들 수 있게 되었다.
